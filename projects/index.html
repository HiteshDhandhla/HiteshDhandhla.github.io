.NET 10 · ASP.NET Core Web API · Entity Framework Core 10 · SQL Server LocalDB

CartFlow API

Completed personal project

Positioned as a practical interview project. The ASP.NET Core backend for the CartFlow Angular app — owns product search, persistent cart state, price calculation, invoice generation and invoice history. Prices and totals are always calculated from database values and never trusted from the frontend.

cartflow-1.png
cartflow-2.png
cartflow-3.png

Workflow

  • Search Products → Add Cart → View Cart → Generate Invoice → Print Invoice
  • Invoice generation runs inside a database transaction and marks the active cart as invoiced
  • Invoice numbers use the INV-yyyyMMdd-0001 format

API surface

  • GET /api/categories, /api/products
  • GET /api/cart, POST /api/cart/items
  • POST /api/invoices, GET /api/invoices/{id}
  • OpenAPI document generation + Swagger UI
